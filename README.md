# 🐂 QurbaniHat - Livestock Booking Platform

**QurbaniHat** is a comprehensive web-based livestock booking platform designed to streamline the experience of finding and reserving animals for the Qurbani season. Built as a part of a specialized web development curriculum, it combines modern UI/UX principles with a robust backend.

---

## ✨ Core Features

- **Secure Authentication**: Integrated login and registration system using **Better Auth**, supporting both traditional Email/Password and **Google Social Login**.
- **Dynamic Animal Listings**: A clean, categorized display of livestock with real-time data fetched from the database.
- **Intuitive UI**: A highly responsive and polished interface built with **Tailwind CSS** and **DaisyUI**, featuring professional navigation, custom footers, and decorative components.
- **Livestock Booking**: Users can easily book specific animals through a streamlined workflow.
- **Personal Dashboard (KeenKeeper)**: A dedicated space for users to manage their bookings and meaningful connections.

---

## 🛠️ Tech Stack

### Frontend & UI

- **Framework**: [Next.js](https://nextjs.org/) (App Router & Client Components)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & [DaisyUI](https://daisyui.com/)
- **Forms**: React Hook Form
- **Icons**: React Icons (FontAwesome)
- **Feedback**: React Toastify (Notifications)

### Backend & Database

- **Authentication**: [Better Auth](https://www.better-auth.com/)
- **Database**: [MongoDB](https://www.mongodb.com/)
- **Logic**: JavaScript (ES6+ Fundamentals)

## 🚀 Installation & Setup

To run this project locally, follow these steps:

### 1. Clone the repository

```bash
git clone [https://github.com/s546863s/QurbaniHat-ass-8.git](https://github.com/s546863s/QurbaniHat-ass-8.git)
cd qurbani-hat
2. Install dependencies
Bash
npm install
3. Environment Configuration
Create a .env.local file in the root directory and add the following keys:

Code snippet
# Better Auth Configuration
NEXT_PUBLIC_BETTER_AUTH_URL=your_site_url
BETTER_AUTH_SECRET=your_auth_secret

# Database
MONGODB_URI=your_mongodb_connection_string

# Social Auth
GOOGLE_CLIENT_ID=your_google_id
GOOGLE_CLIENT_SECRET=your_google_secret
4. Start the development server
Bash
npm run dev
Navigate to http://localhost:3000 to view the application.
```
