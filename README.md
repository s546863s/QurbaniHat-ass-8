# 🐄 QurbaniHat – Livestock Booking Platform

**QurbaniHat** is a modern, user-friendly livestock marketplace designed for the sacred occasion of Qurbani. It provides a platform where users can explore a wide variety of healthy animals, including cows and goats, view their detailed specifications, and book them securely after authentication.

## ✨ Key Features

- **Responsive Design:** A fully optimized experience for Mobile, Tablet, and Desktop users.
- **Dynamic Animal Showcase:** Browse a curated list of animals with real-time filtering and sorting by price.
- **BetterAuth Integration:** Secure login and registration system including Google Social Login.
- **Personalized Shelf:** Users can view and manage their profiles and update information easily.
- **Seamless Booking:** Interactive booking form for logged-in users with instant toast notifications.
- **Optimized Performance:** Built with Next.js Server Components for faster data fetching and LCP optimization.

---

## 🛠️ Tech Stack & Packages

### Core:

- **Next.js 15+** (App Router)
- **Tailwind CSS** (Styling)
- **DaisyUI** (Component Library)
- **BetterAuth** (Authentication with MongoDB Adapter)
- **MongoDB** (Database)

### Additional Packages:

- **React Hook Form:** For efficient form handling.
- **Lucide React:** For beautiful, consistent iconography.
- **React Hot Toast:** For interactive success/error notifications.
- **Lottie-React / Animate.css:** For smooth UI animations.
- **Date-fns:** For professional date formatting.
